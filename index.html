Security & Setup Guidelines

1. Password Hashing (bcrypt)

Passwords must never be saved as plain text. Use bcrypt salt rounds (10+) to compute salted hashes before database persistence.

2. Token Storage Strategy

For web applications, store JWT tokens in HttpOnly, SameSite=Strict cookies to mitigate Cross-Site Scripting (XSS) attacks.

3. Input Sanitization & Validation

Validate input emails using Regex and sanitize data using libraries like express-validator to prevent SQL/NoSQL injection vulnerabilities.
